# Phase 3 activity content review register

Content version: `2026.09-v1`

This register prevents prototype content from being mistaken for clinically or
culturally approved material. The six activities are non-diagnostic cognitive
support exercises. Scores adjust only the next exercise difficulty and must not
be presented as a diagnosis, decline assessment, or treatment recommendation.

## Current activity set

| Activity | Prototype content | Review status |
| --- | --- | --- |
| Memory Match | Matching familiar object symbols | Pending community and accessibility review |
| Object Recall | Cup, key, and book recall | Pending community and accessibility review |
| Pattern Completion | Even-number pattern | Pending cognitive-load and accessibility review |
| Sequence Recall | Tea, key, and book sequence | Pending community and accessibility review |
| Daily Routine Recall | Wake, wash, breakfast ordering | Pending cultural, care, and accessibility review |
| Story Recall | A short market-and-oranges story | Pending language, community, and accessibility review |

## Required approval before pilot use

- Review with older adults and caregivers from the intended NER pilot
  communities, including Assamese-language review before presenting the content
  as Assamese-supported.
- Check that names, routines, objects, symbols, and ordering do not imply a
  single religion, household structure, diet, literacy level, or urban/rural
  lifestyle.
- Test with large font scaling, TalkBack, low vision, hearing impairment,
  tremor/imprecise touch, and cognitive fatigue on representative Android
  devices.
- Record reviewer role, language/community context, date, requested change, and
  approval decision. Approved changes require a new content version.
- Obtain clinical-safety review of instructions and feedback language. No
  activity may claim to diagnose, prevent, or treat a condition.

No external approval has been recorded yet, so `2026.09-v1` remains prototype
content and is not cleared for a field pilot.
